# Top Apps for CTA (Zero-AI accounts)

When `number_of_ai_tools_connected` = 0, use the account's **two most-used apps** (from `top_5_crm_last_30_days` or general app usage) to build a single CTA sentence.

## Template

> Your team's automation with **{App1}** and **{App2}** could be enhanced with AI-powered workflows — a quick way to save time on repetitive tasks.

## Rules

- Use **exactly two** app names
- App names should be display-friendly (e.g. "Salesforce", "Google Sheets", not API slugs)
- Do NOT list all apps or show activity counts
- Do NOT mention "book a call" or sales language
- One sentence only — factual, forward-looking
- If no app names are available, use: "Your team's existing automations could be enhanced with AI-powered workflows."
